# 검수 게이트

## 빌드 게이트 (`build-timeline.mjs`가 출력)
- 씬 타일링: 씬 i.to == 씬 i+1.from, 마지막 == 출력 길이
- 문장 88/88 배정(누락 0), 같은 motion.data 중복 0
- 자막: 한 줄 폭 ≤ 20(한글 1.0·라틴 0.55, 44px·82% 기준), 고아 큐(≤6폭) ≤ 1(단문 예외), 표시 ≥ 0.8s

## 디벨롭 게이트 (`develop-audit.mjs`, 점수 ≥80)
- 훅: 첫 그래픽 ≤10s · 시각 변화 간격 ≤12s · 콜드 오픈 · 약속 카드
- 정적 홀드 ≤8s · 얼굴 구간 오버레이 공백 ≤6s · 자막 큐 ≤3.5s · 카드 텍스트 폭 상한(어절 안 줄바꿈 0)
- 챕터 카드 · 리캡 · 엔드스크린 15s

## 스틸 게이트 (사람이 본다)
- Pretendard 800이 실제로 굵게 나오는가(대체 폰트 조용한 폴백 방지)
- 비트 없는 구간에 빈 무대가 없는가(SceneTitle 폴백)
- 코랄: 화면당 강조 1 + 알약 1 이하, 배경 코랄 금지, 민트 0(스토어)
- 오버레이/카드가 자막·PIP와 겹치지 않는가 (PIP 있을 때 자막 중심 800px)
- 첫 프레임이 풀 프레임인가, 마지막 프레임 카운트/락업 상태가 맞는가
- 실캡처 아닌 화면에 "예시 화면" 배지, 외부 데이터에 출처 크레딧

## 렌더 게이트 (`check.mjs`)
- 길이 = timeline.outSec ± 0.5s · 영상·오디오 트랙 존재 · 스팟 프레임 6장 생성
- 렌더 로그 error 0

## 참고 영상 7함정 매핑 (메이커 에반)
1 순서 뒤집힘 → 음성이 먼저, 화면은 붙는다 · 2 음성 단위 → 촬영본 원음(해당 없음) · 3 자막 밀림 → 단어 타임스탬프 + 컷 후 재계산 · 4 화면 개수·중복·글꼴 → 개수 게이트, 중복 에러, 스틸 확인 · 5 캡처 사고 → 실캡처 최소화, 확대 검수 · 6 생성 도구 → 한글 텍스트 금지, 실패 시 같은 프롬프트 재시도 · 7 업로드 → 공개 버튼은 사람
