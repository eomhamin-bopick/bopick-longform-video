# 객관식 인터뷰 12문항 (AskUserQuestion, 4문항 × 3라운드)

라운드 1 — 형식·톤·자막·전사
1. **화면 구성** — 그래픽 풀화면+얼굴 원형 PIP (Rec) / 얼굴 메인+오버레이 카드 / 컷어웨이 전환 / 구간별 혼용
2. **브랜드 톤** — 보픽플래너(블루 계열, 핀이) (Rec) / 보픽 마스터(블루 단색) / 보픽스토어(블루+코랄, 보둥이) / 다크 변형
3. **자막 스타일** — 문장 2줄+키워드 브랜드색 (Rec) / 단어 팝업(카라오케) / 문장+상단 챕터 바 / 자막 최소
4. **전사 확보** — 지금 ElevenLabs STT (Rec) / 촬영 원고 있음(글자=원고, 타이밍=STT) / 나중에 / 로컬 Whisper

라운드 2 — 연출·소재·컷·변경
5. **코드 모션 유형(복수)** — 플로우차트·다이어그램 / 수치 카운트업·통계 / 챕터 스파인·번호 카드·체크리스트 / 키워드 타이포
6. **소재(복수)** — 앱 캡처→폰/브라우저 목업 / Higgs 이미지 B-roll / Higgs 영상 B-roll / 캐릭터 리액션
7. **컷 편집** — STT 기반 무음·군말 자동 컷(승인제) (Rec) / 긴 침묵만 / 수동 컷 리스트 / 그대로
8. **변경 방식** — 매니페스트 정본+재렌더 (Rec) / 대화로 지시 / Studio 조정 / 둘 다(정본+미리보기)

라운드 3 — 전사 결과 기반 (전사·챕터 분석 후)
9. **톤 재확인** — 내용의 대상(소비자/설계사)에 맞는 브랜드로 전환 제안. 가이드 근거를 옵션 설명에 적는다
10. **구간 레이아웃 기본값** — 훅·따라읽기·CTA=얼굴, 설명=그래픽+PIP (Rec) / 훅만 얼굴 / 얼굴 기본+순간만 그래픽 / 챕터 안 반전 지점에서 전환
11. **원고 기반 추천 연출(복수)** — Phase 2 분석에서 나온 항목을 그대로 옵션으로(예: 연령 타임라인 바 / 세대 비교표 / 대비 카드+스택 / 인용·캡처 배치)
12. **CTA 소재** — 실제 캡처 제공 / 랜딩 캡처 / Higgs 예시(배지) / 얼굴+화살표만

작성 규칙: 옵션 설명 1줄에 트레이드오프. 답변 문자열에 사용자가 덧붙인 요청("앞으로도 ~해줘")이 있으면 메모리·스킬에 반영한다.
