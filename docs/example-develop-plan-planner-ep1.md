## 3. 본문 가독성
- `20개 전산`(1:30~1:45): 8초 후 2단계 — 보험사 로고 대신 "20개" 아래에 항목 칩이 4개씩 채워지는 `checklist`로 교체, 또는 `statCount` 뒤 `keywordTypo "하루 3시간"`.
- `고객은 이미 다이렉트 비교 다 해봄 vs 설계사는 아직도 손으로 전산 치는 중`: `eitherOr` a/b 폭 상한 12 → `a:"고객은 이미\n다이렉트 비교", b:"설계사는 아직\n손으로 전산"`.
- 인용 카드(3:30 택시, 4:30 20분의 1, 5:15 소개 계약): 카드 폭 60% 이상으로 키우거나 `keywordTypo`(풀블리드)로 전환. 본문 32px 이상.
- `0시간→5분`: `statCount` 대신 값 고정 카드 `"1시간 → 5분"` + 링 채움(countdown 변형) — 카운트업 시작값이 의미를 깨는 경우.
- 얼굴 구간(3:00, 3:15, 5:45): 6초 넘는 곳에 `keywordChip`(문장 키워드).
